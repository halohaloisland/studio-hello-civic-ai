# 🏛️ Studio Hello 市民会議 統合AI管制システム

**スタジオハロー（定員30名：会場参加20名＋リモート参加5名）** の保有機材をすべて統合し、ハイブリッド市民会議を円滑に進行・可視化・記録するためのオールインワンWebアプリケーションです。

単一のHTMLファイル（`index.html`）で構成されており、外部サーバー不要でGoogle Chrome上から即座に稼働します。

---

## ✨ 主な機能

1. **👥 ハイブリッド25名話者識別（AI声質識別 × 電子ペンワンタップ固定）**
   - 同一のGoogleアカウント（会場ミキサー経由）から発言する**会場20名**と、Google Meet上の**リモート5名**を、声質・トーン・文脈からGemini AIが自動識別します。
   - 左上の**25名パレット**を電子ペン（エプソン EB-1410WT）でタップすることで、次の発言者を確実にロック（優先指定）することも可能です。
2. **📋 リアルタイムAIグラレコ（4象限ボード）**
   - 議論の内容を **「💡 主要な意見・提案」「⚠️ 課題・議論のポイント」「🤝 合意事項・ネクストアクション」「📊 AIリサーチ・ファクトデータ」** の4象限へ自動分類・箇条書き化します。
3. **🧠 インタラクティブ・マインドマップ（1分毎自動更新＆API不要即時同期）**
   - 1分ごとにAIが会話全体の階層構造を解析し、議論のつながりをツリー図へ自動更新します。
   - APIを使用しない「⚡ 即時ツリー反映」や、電子ペンでのノード開閉（`＋`/`−`）・ダブルタップ編集・ズーム移動にも対応しています。
4. **✏️ EB-1410WT 電子ペン直接描画 ＆ スライド履歴管理**
   - AIが生成したグラレコやマインドマップの上から、**赤ペン・青ペン・蛍光マーカー・消しゴム**で直接手書き加筆ができます。
   - 議論の区切りごとに「＋ 新規スライド作成」でボードを切り替え、過去のスライド（手書きレイヤー含む）もワンタップで振り返れます。
5. **🔍 AI自律リサーチ（バックグラウンド自動検索＆ファクト投影）**
   - 会話中に「統計数値・条例・自治体事例・制度仕様・専門用語」など裏取りが必要な話題が出ると、AIが自律判断してGoogle検索を実行し、出典リンク付きの要約カードを表示します。
   - カードの **「📌 グラレコ＆マップに貼る」** を押すと、中央ボードと150インチ投影画面に根拠データが即座に追加されます。
6. **⏱️ マグネット吸着式 進行タイマー ＆ アジェンダテロップ**
   - ボード上に「現在のアジェンダ（テロップ）」と「カウントダウンタイマー」を重ねて表示します。
   - ドラッグ操作で画面の**6箇所（上下の左・中央・右）へ磁石のように自動吸着**し、残り1分で黄色警告、0秒で赤色点滅＋終了チャイムが鳴ります。
7. **🪟 150インチ4K投影用サブウィンドウ ＆ 議事録HTML一括保存**
   - 投影専用のクリーン画面を別ウィンドウで切り出し、iMac 27インチ経由で150インチ4Kスクリーンへリアルタイム投影できます。
   - 会議終了後は「💾 議事録＆マップ保存」から、**全スライド画像＋マインドマップSVG＋話者識別付き全発言ログ**を1つのHTMLファイルとしてダウンロードできます。

## 🛠️ 事前準備・動作環境

- **推奨ブラウザ**: Google Chrome（最新版）
- **必要なもの**: **Gemini API Key**（`AIza...` で始まるキー。画面右上の入力欄に設定するとブラウザ内に自動保存されます）
- **推奨端末配置**:
  - **MacBook Air (M2) ＋ エプソン EB-1410WT**: 本アプリを操作し、Google Meetに**「コンパニオンモード」**で入室して画面共有・電子ペン描画を行います。
  - **iMac 27インチ (2019) ＋ 150インチ4Kプロジェクター**: Google Meetのホスト進行を行い、150インチ大画面へ「AIグラレコ＋リモート5名の表情」を拡張投影します。

## 🚀 当日の操作手順（クイックガイド）

### 1. 音声の接続（開始15分前）
1. Chromeで本アプリのURLを開き、上部の入力欄に **Gemini API Key** を貼り付けます。
2. **「① Meetタブ音」** をクリックし、Google Meetのタブを選択して **「タブの音声を共有」をON** にします（リモート5名の音声取得）。
3. **「② 会場音(A-6)」** をクリックし、アナログミキサーの `REC OUT` を接続したオーディオ入力を許可します（会場20名の音声取得）。

### 2. 会議AIの稼働
1. **「▶ 会議AI稼働」** をクリックすると、14秒ごとの音声話者識別・グラレコ更新、45秒ごとのAI自律リサーチ、1分ごとのマインドマップ自動更新がスタートします。
2. 必要に応じて左上の **「名簿編集」** から当日の参加者25名の名前を登録します。

### 3. 会議中の進行・描画操作
- **話者の手動指定**: 会場で発言者が変わったら、左上の25名パレットを電子ペンでタップします（発話後に自動でロック解除されます）。
- **表示モード切替**: 議論のフェーズに合わせて上部の **「📋 4象限グラレコ」「🧠 マインドマップ」「📐 上下分割(両方)」** を切り替えます。
- **電子ペン加筆**: ツールバーで `✏️ 赤ペン` や `蛍光` を選んでボードに直接書き込みます。マインドマップの枝を開閉したいときは `👆 ノード操作/移動` に切り替えます。
- **タイマー＆テロップ**: 2段目ツールバーから時間（`1分`〜`15分`）をセットして `▶ 開始` を押し、進行に合わせてアジェンダチップをタップします。

### 4. 150インチ4Kスクリーンへの投影
- 上部の **「🪟 150型投影ウィンドウ」** を押して投影専用ウィンドウを開き、Google Meetのウィンドウ共有対象に指定します（操作ツールバーが隠れた見やすい画面が共有されます）。

### 5. 会議終了時の記録保存
- **「■ 停止」** を押した後、**「💾 議事録＆マップ保存」** をクリックすると、当日の日付入りの統合議事録HTMLファイルがダウンロードされます。

アプリ上部の **「🎛️ ② 4大サブシステム配線図＆当日点検ボード」** タブから、設営時にいつでも以下の配線マトリクスとチェックリストを確認できます。

| サブシステム | 担当機材 | 主な役割 |
| :--- | :--- | :--- |
| **① AIグラレコ＆描画系** | MacBook Air (M2) / エプソン EB-1410WT | 本アプリの稼働、25名話者識別、電子ペン直接加筆 |
| **② マルチカメラ収録系** | GH5 / HDR-MV1 / HVR-S270J / ATEM Mini Pro ISO / SSD / JVA06 | 3カメスイッチング、SSD個別ISO収録、Meetカメラ入力 |
| **③ 会場PA＆双方向音響系** | アナログミキサー / CLASSIC PRO PA-UNO ×2 / YAMAHA AG03 | 会場20名への拡声、ミックスマイナスによるエコーゼロ通話 |
| **④ メイン管制＆4K投影系** | iMac 27インチ (2019) / 4Kプロジェクター / 150型スクリーン | Meetホスト進行、150インチ大画面への拡張投影 |

### ⚠️ ハウリング・エコー防止の必須設定（設営時厳守）
- **アナログミキサー**: 「AG03戻りチャンネル」の **AUXツマミを必ず `0（ゼロ）`** に絞り切る（リモート音声の逆流防止）。
- **YAMAHA AG03**: `TO PC` スイッチを **`INPUT MIX`（中央）** に固定し、**`MONITOR MUTE` を ON（押し込み）** にする。
- **j5create JVA06**: 側面のオーディオスイッチ3個を **すべて `OFF`** にする。
- **MacBook Air (M2)**: Google Meet入室時は必ず **「コンパニオンモードを使用」** を選択する。

## ❓ トラブルシューティング

- **音声が認識されない場合**:
  - ブラウザのURLバー左側の鍵（または設定）アイコンから「マイク」の権限が許可されているか確認してください。
  - 「① Meetタブ音」の共有ダイアログで「タブの音声を共有」にチェックが入っているか確認してください。
- **エコーやハウリングが発生する場合**:
  - MacBook Air M2 のスピーカー音量がミュートになっているか、また「コンパニオンモード」で入室しているか確認してください。
  - アナログミキサーのAG03戻りチャンネルの `AUX` が `0` になっているか再確認してください。
